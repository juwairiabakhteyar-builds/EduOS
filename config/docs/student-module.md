# Student Module

## Purpose

Manage the complete lifecycle of every learner in EduOS.

---

## Primary Users

- Administrator
- Admission Office
- Teachers
- Parents (Limited)
- Students (Limited)

---

## Core Information

- Student ID
- Admission Number
- Full Name
- Date of Birth
- Gender
- Institution
- Academic Session
- Class
- Section
- Guardian
- Contact Details
- Status
